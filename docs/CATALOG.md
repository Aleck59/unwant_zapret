# Формат каталога

Каталог — это набор файлов JSON. Один комплект приезжает вместе с программой
и обновляется вместе с ней. Второй лежит в `C:\ProgramData\Strazh\catalog.d\`
и принадлежит человеку: обновление программы его не трогает.

Записи из второго перекрывают первый по полю `id`.

## Файл

```json
{
  "version": 1,
  "comment": "Необязательное пояснение ко всему файлу",
  "targets": [ … ]
}
```

Ошибка в одной записи не теряет остальные: плохая запись пропускается, а
причина показывается в разделе «Обзор» и в `strazh-cli status`.

## Запись

```json
{
  "id": "qihoo-360",
  "name": "360 Total Security / 360 Safeguard",
  "vendor": "Qihoo 360",
  "category": "cn-security-suite",
  "severity": "high",
  "enabled": true,
  "why": "Ставит несколько служб и драйвер самозащиты, подменяет домашнюю страницу…",
  "references": ["https://en.wikipedia.org/wiki/Qihoo_360"],
  "match": { … },
  "actions": ["block_exec", "block_install", "block_network", "neutralize_services"]
}
```

| Поле | Обязательно | Что означает |
| --- | --- | --- |
| `id` | да | Код записи. Буквы, цифры, `-`, `_`, `.` |
| `name` | да | Название для человека |
| `vendor` | нет | Издатель |
| `category` | нет | Раздел, см. ниже. По умолчанию `other` |
| `severity` | нет | `low`, `medium`, `high`. По умолчанию `medium` |
| `enabled` | нет | По умолчанию `true` |
| `why` | нет | **Почему запись в списке.** В поставляемом каталоге обязательно и проверяется в сборке |
| `references` | нет | Ссылки на источники |
| `match` | да | Признаки, хотя бы один |
| `actions` | нет | По умолчанию `block_exec` и `block_install` |

## Признаки (`match`)

Все списки нечувствительны к регистру и понимают маски `*` и `?`. Пустой
список означает «признак не используется», а не «подходит всё».

| Признак | Пример | Замечание |
| --- | --- | --- |
| `executables` | `["360tray.exe"]` | Точные имена уходят в перехват запуска, имена с масками — в правила по пути |
| `installers` | `["360*setup*.exe"]` | Действует, если у цели есть `block_install` |
| `original_filenames` | `["360Safe.exe"]` | `OriginalFilename` из ресурса версии. **Переименование его не меняет** |
| `product_names` | `["360 Total Security"]` | Ищется вхождением |
| `publishers` | `["Qihoo 360"]` | Ищется вхождением в подпись и в `CompanyName`. Самый устойчивый признак |
| `paths` | `["*\\360\\*"]` | `/` и `\` равнозначны |
| `sha256` | `["a1b2…"]` | 64 знака. Единственный признак, который нельзя обойти |
| `services` | `["ZhuDongFangYu"]` | Маски разворачиваются по установленным службам |
| `scheduled_tasks` | `["*360*"]` | |
| `domains` | `["360safe.com"]` | Только имя: без схемы, пути и пробелов |

## Действия (`actions`)

| Действие | Что включает |
| --- | --- |
| `block_exec` | Перехват запуска и правила по пути |
| `block_install` | То же для установщиков плюс карантин найденного |
| `block_network` | Правило брандмауэра для найденных на диске файлов |
| `block_domains` | Записи в hosts (если механизм включён) |
| `neutralize_services` | Остановка служб и отключение заданий |
| `quarantine` | Явное требование карантина |

## Разделы (`category`)

`cn-security-suite`, `av-bundleware`, `rogue-security`, `system-optimizer`,
`driver-updater`, `ru-bundleware`, `stalkerware`, `adware-installer`,
`remote-access-abused`, `miner`, `crack-tool`, `other`.

## Чего каталог не примет

Маску, задевающую системный файл. `lsass.exe`, `explorer.exe`, `*.exe` —
такая запись не «не сработает», её отвергнут при чтении с объяснением, а
окно не даст её сохранить. Проверка стоит в трёх местах: при чтении, при
построении индекса и при построении плана.

## Проверить свой файл

```bash
python tools/validate_catalog.py C:\ProgramData\Strazh\catalog.d
```

Команда покажет число записей, размер плана по каждому механизму и список
замечаний. Ненулевой код возврата означает, что хоть одна запись не принята.
