# Механизмы: что именно программа делает с системой

Каждый раздел отвечает на три вопроса: что меняется, почему выбран этот
способ и что он **не** может.

## Перехват запуска по имени файла (IFEO)

**Что.** В `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File
Execution Options\<имя.exe>` заводится значение `Debugger`, указывающее на
`strazh-deny.exe`. Windows запускает обработчик вместо программы и передаёт
ему исходную строку запуска.

**Почему.** Это единственный способ запретить запуск, который работает на
всех изданиях Windows, включая домашние, где нет ни AppLocker, ни редактора
групповых политик. Срабатывает до первой инструкции запрещаемой программы.

**Чего не может.** Ключ называется именем файла — маски там невозможны, а
переименованный файл через него не поймать. Этим занимается наблюдатель за
процессами.

**Отмена.** Значение удаляется; если ключа до нас не было — удаляется и он.
Чужое значение `Debugger` запоминается и возвращается на место.

**Осторожность.** Слишком общие имена (`setup.exe`, `update.exe`,
`launcher.exe`) в перехват не попадают вовсе: такое имя встречается у сотен
программ. Они уходят в правила по пути, где рядом стоит проверка издателя.

## Правила по пути и маске (SAFER, SRP)

**Что.** В `HKLM\SOFTWARE\Policies\Microsoft\Windows\Safer\CodeIdentifiers`
уровень по умолчанию ставится «разрешено», а под `\0\Paths` заводятся
запрещающие правила с масками. Каждое помечено описанием `Strazh: <цель>`.

**Почему.** Умеет то, чего не умеет перехват по имени: маски и запрет по
месту установки. Работает на уровне загрузчика образов.

**Чего не может.** Ничего не знает об издателе; проверка библиотек намеренно
отключена (`TransparentEnabled=1`) — она тормозит машину и ломает программы,
которые грузят свои модули из временных папок.

**Отмена.** Удаляются правила из списка изменений и, отдельно, все правила с
нашей пометкой — на случай, если файл состояния потерян. Чужие правила SAFER
не трогаются никогда.

## Наблюдение за процессами

**Что.** Раз в секунду снимается список процессов. Для каждого нового
собираются признаки — имя, полный путь, `OriginalFilename` и `CompanyName` из
ресурса версии, при нужде подпись Authenticode — и сверяются с каталогом.
Совпавший процесс снимается.

**Почему.** Единственный слой, который ловит переименованный файл.
`OriginalFilename` лежит в ресурсе версии и переименование его не меняет;
подпись издателя не меняется тем более.

**Чего не может.** Срабатывает уже после запуска: несколько миллисекунд
программа успевает поработать. Против уже установленного защитного пакета
этого мало — там нужны службы и брандмауэр.

## Наблюдение за загрузками

**Что.** Папки загрузок и рабочего стола всех учётных записей плюс временные
папки. Новый `.exe`, `.msi`, `.scr` проверяется по всем признакам, включая
контрольную сумму; совпавший уезжает в карантин.

**Почему.** Запрет установки начинается раньше запуска: установщик сначала
попадает на диск.

**Чего не может.** Не видит того, что скачано мимо этих папок. Файл, который
прямо сейчас пишут, намеренно пропускается: иначе наблюдатель утащил бы
недокачанный установщик.

## Службы и задания планировщика

**Что.** `sc stop`, `sc config start= disabled`, `schtasks /Change /Disable`.
Прежний тип запуска службы читается из реестра и запоминается.

**Почему.** Защитные пакеты держатся на машине не файлом, а службой, которая
её же и восстанавливает. Без этого шага остальные бесполезны.

**Отмена.** Тип запуска возвращается в то значение, в каком его застали.

## Правила брандмауэра

**Что.** `netsh advfirewall firewall add rule` на входящие и исходящие для
конкретных файлов.

**Почему.** Запретить запуск задним числом нельзя, а отрезать сеть — можно.
Обычно этого достаточно, чтобы программа перестала обновляться, тянуть
довесок и отправлять собранное.

**Чего не может.** `netsh` принимает только настоящий путь, без масок.
Поэтому пути берутся не из каталога, а из осмотра машины: что сейчас
работает и что нашлось среди установленных программ.

## Закрытие адресов (hosts)

**Что.** В `%SystemRoot%\System32\drivers\etc\hosts` добавляется помеченный
блок с записями `0.0.0.0 домен` и `0.0.0.0 www.домен`.

**Почему.** Мешает скачать установщик и отправить собранное.

**Выключено по умолчанию.** Файл общий для всей машины, и запись,
поставленная сгоряча, потом ищется часами. Программа читает и переписывает
только содержимое своего блока; всё остальное в файле остаётся нетронутым, а
прежнее содержимое сохраняется при первом применении.

## Защита Windows от нежелательных программ (PUA)

**Что.** `Set-MpPreference -PUAProtection Enabled`.

**Почему.** У Защитника есть отдельный фильтр ровно того класса программ,
ради которого написана эта программа, и он выключен по умолчанию. Одна
галочка полезнее любого собственного правила.

**Отмена.** Возвращается прежнее значение. Если раньше стоял режим «только
сообщать», после отката будет он, а не «выключено».

## Запрет запуска из оболочки

**Что.** `DisallowRun` в ветке пользователя.

**Почему.** Стоит дёшево, работает без прав администратора и закрывает самый
частый способ запуска — двойным щелчком.

**Выключен по умолчанию.** Действует только на проводник и обходится
переименованием; без остальных слоёв создаёт ложное чувство защиты.
